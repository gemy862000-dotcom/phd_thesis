# An Integrated AI-Based Framework for Test Automation

This project is a prototype implementation for a PhD thesis proposal on AI-based software test automation.

## Features

- Defect prediction
- Test prioritization
- Self-healing
- Automated test case generation
- Explainability
- Benchmark-based evaluation
- CI/CD export hooks

## Project Structure

```text
ai_test_automation_project/
├── app.py

├── sample_defect_data.csv
├── README.md
├── core/
├── models/

├── examples/

```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
